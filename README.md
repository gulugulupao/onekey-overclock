# 一键超频 OneKey-OC

> 在飞牛 OS（fnOS）arm 设备上，**不重编译内核**就能给大核超频的小工具。无需 Docker、不依赖任何第三方应用。

适用于 Amlogic A311D 等 CPU 的 ARM 飞牛设备（如网心云 OES）。通过改写系统底层频率与电压实现一键切换档位，内置自愈回滚与硬件看门狗保护，确保您玩得起、也退得回。

## 🎛️ 四档位

| 档位 | 大核频率 | 说明 |
| --- | --- | --- |
| 🐣 乖巧 | 2.2 GHz | 出厂频率，最稳妥 |
| 🐆 野兽 | 2.4 GHz | 常用高频，性能与功耗均衡 |
| 🔥 狂暴 | 2.5 GHz | 全速冲刺，务必配合良好散热 |
| ☄️ 焚天 | 2.64 GHz | 极限高频，专属改装散热机箱，自担风险 |

## ✨ 核心特性

- **无需重编译内核**，开箱即用
- **自愈回滚**：任何异常一键回到出厂频率与电压
- **一键重置**：干净退出，随时可审计可回退
- **硬件看门狗可选**：异常时自动纠错
- **日志可视化**：近 7 天运行日志一键导出
- **全新仪表盘**：渐变能量弧 + 发光光点 + 中央频率读数，三档一目了然
- **温度优先提醒**：高频满载时提示关注核心温度与散热

## 📦 双版本安装包

| 安装包 | 后端运行时 | 适用场景 |
| --- | --- | --- |
| `一键超频_v1.1.0_node.fpk` | 自带 aarch64 node | 环境特殊、追求最大兼容性 |
| `一键超频_v1.1.0_lite.fpk` | 复用宿主 Python3 | 轻量干净、默认推荐 |

> 💡 **一句话选法**：两种包使用**完全相同的底层超频代码**，仅 Web 小后端的运行时不同。99% 的标准飞牛设备直接装**精简版（lite）**即可；只有遇到 Web 界面打不开、日志明显报 Python 后端异常时，再换 **Node 版**。

## 🔨 从源码构建

```bash
# 在 one_oc_build/ 目录下
python build_both.py
```

产物会输出到上层 `一键超频_releases/` 目录，生成 `一键超频_v1.1.0_node.fpk` 与 `一键超频_v1.1.0_lite.fpk`。

> 说明：Node 版所需的 aarch64 node 运行时体积较大，位于 `onekey-overclock/app/runtime/`，已按 `.gitignore` 规则排除出本项目，构建前请自行准备。

## 🚀 安装

1. 下载对应设备环境的 `.fpk` 安装包。
2. 飞牛 OS **应用中心 → 右上角手动安装** → 选择该文件导入。
3. 在应用内选择档位即可生效。

## 🌡️ 使用前提 · 供电与散热

- **散热优先**：长时间高频满载时，核心温度可能逼近 **85°C 温度墙**并触发自动降频保护。请确保风道与主动散热正常，先看温度、再定档位。
- **供电余量**：12V/3A（36W）电源预算下，插满机械盘高速读写或组建 RAID 阵列时，建议避免叠加高频档。
