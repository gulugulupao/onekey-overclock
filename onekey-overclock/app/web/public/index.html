只要内核已加载超频档位，三个档位之间切换即实时生效、无需重启； 仅首次从默认进入野兽/狂暴档需重启一次换 DTB。「乖巧」始终为出厂频率、即时生效。 任意未授权重启 / 宕机 / 断电后再开机，将自动回落默认频率，杜绝变砖。 （硬件看门狗为可选保险，非强制）

供电注意（12V/3A=36W 电源预算）：若插满 3 块机械硬盘且同时高速读写，总功耗会逼近甚至超出 36W 上限，导致 12V 跌压、CPU 掉压不稳——此类场景建议降至「野兽」档或改用 SSD。RAID 0 / 1 / 5 组阵列会令多盘同时满负荷，同样加速抢电，请将其视为"满载机械盘 + 高频档"风险叠加。

🌡️散热提醒（温度优先）：频率拉高后 CPU 发热会明显上升。「狂暴」档满载长时间运行时，若机箱被动散热 / 通风不畅 / 积灰，核心温度可能逼近 85°C 温度墙并触发自动降频保护，长期高温也会加速老化。请务必确保良好风道与主动散热后再使用高频档，并在烧机时观察温度曲线。
